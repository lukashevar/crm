# Паспорт проекта CRM

## 01. Цель проекта
Создать универсальную CRM для личного использования с возможностью расширения до командной работы.

## 02. Принципы разработки
- Модульный монолит.
- Адаптивный интерфейс для компьютера и телефона.
- Постепенная разработка с тестированием.
- Понимание архитектуры и самостоятельное написание кода.

## 03. Планируемые возможности
- Единый календарь событий и задач с фильтрами.
- Контакты и связь с событиями.
- Повторяющиеся события: редактирование одного экземпляра или всей серии.
- Несколько пользователей и совместная работа в перспективе.

## 04. Технологии
- Backend: Python, FastAPI, SQLAlchemy 2.x, Alembic.
- База данных: PostgreSQL.
- Frontend: React, TypeScript, CSS.
- Инструменты: Git, VS Code, pytest.

## 05. Основные сущности
- User — пользователь.
- Workspace — рабочее пространство.
- WorkspaceMember — участник рабочего пространства.
- Contact — контакт.
- Event — событие с началом и окончанием.
- Task — задача со статусом и сроком.
- EventSeries — серия повторяющихся событий.
- EventContact — связь события с контактом.

Состав сущностей и связи уточним при проектировании БД.

## 06. Этапы разработки
1. Настроить Python-окружение и запустить FastAPI.
2. Подключить PostgreSQL.
3. Спроектировать модели данных.
4. Реализовать CRUD API и тесты.
5. Добавить контакты, задачи и повторяющиеся события.
6. Разработать интерфейс.
7. Добавить авторизацию и разграничение доступа.

## 07. Правила обучения
- Сначала объяснение архитектуры, затем небольшое задание.
- Пользователь пробует самостоятельно.
- Ошибки и вопросы разбираем до перехода дальше.
- После завершения этапа обновляем PROGRESS.md.
- Существенные архитектурные решения фиксируем в паспорте.

## 08. Текущий статус
Разработка не завершена. Технический фундамент ещё настраивается. Точное место остановки и выполненные задачи записываем в PROGRESS.md.
